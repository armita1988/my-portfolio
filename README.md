## Run Locally

Clone the repository:

```bash
git clone https://github.com/armita1988/my-portfolio.git
cd my-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

Create a production build:

```bash
npm run build
```
